# Contributing

Thanks for helping improve Remote Clinic.

## Principles

- Keep the core app local-first.
- Use synthetic data only.
- Do not add real patient data.
- Do not add medical advice or diagnostic claims.
- Label simulation results clearly.
- Prefer reproducible seeds and tests for simulation changes.

## Development

```bash
npm install
npm run dev
npm run test
npm run build
```

## Pull Requests

Good pull requests explain:

- what changed
- why it matters
- how it was tested
- whether the change affects scientific interpretation
