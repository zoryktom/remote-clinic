# AI Model

Clinic AI is a local-first assistant. The shipped implementation is structured and deterministic.

It can:

- summarize patient timelines
- identify unresolved workflow tasks
- answer structured research questions
- show evidence and source events
- report limitations

It cannot:

- diagnose
- prescribe
- provide real clinical advice
- invent patient events
- invent experiment results

Optional local model integration can be added later through an offline-compatible runtime such as Ollama.
