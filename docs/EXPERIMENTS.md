# Experiments

The current build includes an A/B experiment:

- Scenario A: offline, no AI
- Scenario B: offline, local structured AI

The same seed family is used for comparison.

Metrics include:

- patients served
- care gaps created
- care gaps resolved
- average wait
- resource utilization
- AI queries
- AI errors
- connectivity downtime
- power used
- staff workload
- cost

Results are measured when the experiment is run in the app. They are not preclaimed in documentation.
