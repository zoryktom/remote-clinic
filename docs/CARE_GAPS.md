# Care Gaps

A care gap is an unresolved simulated workflow.

Examples:

- referral incomplete
- follow-up overdue
- abnormal result pending
- medication reconciliation needed
- transportation barrier
- preventive task due

Each care gap stores:

- ID
- patient
- type
- created day
- status
- severity
- evidence
- related event IDs
- resolution

The player resolves care gaps by reviewing the evidence rather than trusting a hidden answer key.
