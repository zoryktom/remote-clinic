# Simulation Model

The simulation is deterministic when given the same world and simulation seeds.

## State

The state includes:

- synthetic patients
- care gaps
- resources
- power
- connectivity
- weather
- AI metrics
- events
- experiments
- score

## Day Advancement

Advancing a day updates weather, connectivity, resources, patient throughput, care gaps, AI failures, and scores.

## Scientific Status

All outputs are simulation outputs. They are useful for exploring workflow hypotheses, not for predicting real clinical outcomes.
