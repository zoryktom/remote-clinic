# Methodology

Remote Clinic experiments are simulation experiments.

## Procedure

1. Select a deterministic seed.
2. Configure population, staff, connectivity, AI, power, transportation, supplies, weather, duration, and run count.
3. Run the simulation.
4. Store metrics, event samples, failures, and reproducibility metadata.
5. Compare scenarios with matched seeds when appropriate.

## Interpretation

Results are **SIMULATION RESULT** only. They do not establish real-world clinical effectiveness, safety, staffing needs, or infrastructure recommendations.
