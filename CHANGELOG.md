# Changelog

## 0.1.1 - 2026-10-07

- Improved first-time player onboarding with a concise opening explanation and Start Day flow.
- Added a replayable How To Play panel, persistent current objective, work queue, and clinic status panel.
- Added patient next-action buttons and a visual patient workflow from arrival through follow-up.
- Added immediate positive/warning feedback, day-complete results, bottleneck view, map labels, and an understandable connectivity failure scenario.
- Made the initial scenario a simple three-patient normal day before disruptions appear.

- Added buildable voxel blocks and in-world interaction.
- Added synthetic patient generation, timelines, and care gaps.
- Added local structured Clinic AI with evidence panels and failure explorer.
- Added power, connectivity, resources, transportation, and weather constraints.
- Added Research Lab A/B experiments and JSON, CSV, JSONL, Markdown exports.
- Added automated tests for generation, care gaps, resources, AI queries, prompt-injection handling, experiments, and exports.
- Added open-source docs, license, citation metadata, and GitHub Pages workflow.
